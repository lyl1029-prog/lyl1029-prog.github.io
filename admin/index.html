Export & Deploy

When you're done editing, export all JSON files and upload them to your hosting to update the live site.

Step 1 — Export JSON Files

Download the updated content files. Upload them to your hosting's /data/ folder, replacing the old ones.

Step 2 — Deploy to Netlify (Recommended)

Upload the entire project folder (including the updated JSON files) to Netlify Drop for instant deployment.

🌐 Go to Netlify Drop

Step 3 — GitHub Pages

Push the updated JSON files to your GitHub repository, then GitHub Pages will automatically rebuild the site.
